## 排障方法论

每篇文档遵循相同的推理链：**现象 → 排查过程 → 根因 → 解决方案 → 验证**。

这不是 Wiki，是**可复现的排障记录**。每篇都包含：
- 示波器/逻辑分析仪截图或日志证据
- 完整的排查步骤（可复现）
- 根因分析（为什么，不是是什么）
- 验证数据（修复后的实测结果）
