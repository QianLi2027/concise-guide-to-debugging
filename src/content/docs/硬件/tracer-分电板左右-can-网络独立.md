## 现象

Tracer 方形分电板（自研板）把整机 CAN 线束分到左右两组端子上，每组端子只有 `CAN_H` / `CAN_L` / `GND` 三芯。调试时按"分电板就是一条总线分出来的多个口"的直觉，把 USB-CAN 适配器接到左侧端子后扫描节点：

- 左侧节点全部正常应答；
- 右侧节点全部无应答，整侧离线，总线上既没有错误帧，也没有总线关闭（bus-off）报警。

把适配器换到右侧端子重扫，现象完全对称：右侧全部应答，左侧全部消失。

## 排查过程

1. 断电，万用表通断档量左右端子：`CAN_H`—`CAN_H`、`CAN_L`—`CAN_L`、`GND`—`GND` 全部不导通。
2. 看板上器件：只有接线端子与配电部分，没有任何 CAN 收发器、隔离器或网桥芯片，板子不会在两组端子之间转发报文。
3. 因此"单侧离线"不是通信故障，而是拓扑理解错误：适配器只挂在其中一张网上，另一张网根本没有调试节点。
4. 顺带确认终端电阻：两组端子都没有板载 120Ω，终端只能由各网的末端节点提供。

## 根因

分电板的左右 CAN 是两组**互不导通的无源端子排**，不是同一条总线的两个分线口。左右两侧在网络层是两张独立的 CAN 网，跨侧报文不会被任何器件转发，也不会出现在对侧通道上。

这种布局把左右两侧拆成两张网：单侧短路、总线关闭或终端缺失只影响本侧，代价是调试时必须分别接入。

## 解决方案

调试时按"两张网"处理，各自组建：

1. **通道**：用两个独立的 USB-CAN 适配器（或一个双通道适配器），左通道接左侧端子，右通道接右侧端子；两侧 `CAN_H`/`CAN_L` **不得并接**。
2. **终端电阻**：分电板不提供，各网两端各 120Ω，由末端节点或适配器提供。断电在端子上量 `CAN_H`—`CAN_L`，两端各 120Ω 时应为 60Ω。
3. **共地**：两组端子的 `GND` 都引自分电板配电地，整机共参考地；使用隔离型适配器时，保证隔离侧参考地与所接网络一致。
4. **上位机**：两条通道分别设成相同波特率，各自扫描节点；需要跨侧联调时在上位机层转发报文，不要指望分电板桥接。
5. **线束复检**：接线后用通断档复核左右 `CAN_H`/`CAN_L` 仍不导通。误并接会把两张网合成一张，终端电阻并联后总线阻抗跌到 30Ω 量级，两侧共模差还会引入随机错误帧。

## 验证

- 断电测量：每侧 `CAN_H`—`CAN_L` 为 60Ω（两端各 120Ω 时）；左右 `CAN_H`—`CAN_H` 开路。
- 单通道扫描只列出本侧节点；切到另一通道，节点列表整体替换，两侧无交集。
- 两侧同时运行，各通道错误计数不增长；拔掉某一侧末端节点，只有该侧出现错误帧或离线。
