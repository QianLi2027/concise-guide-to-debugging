## 现象

达妙 MC02 驱动器，按手册推荐 `Kp=0.8, Ki=0.05` 整定电流环，空载正常，加载至 iq=2 A 后电流剧烈振荡，驱动器过流保护。

## 排查过程

1. 用上位机抓取 iq/id 波形，确认振荡频率约 1.2 kHz，接近电流环带宽极限。
2. 逐步降低 `Ki` 至 0.01，振荡幅值减小但未消失。
3. 测量电机相电阻/相电感，发现手册推荐参数基于 `Ls=0.3 mH` 的电机，实际电机 `Ls=0.08 mH`。

## 根因

PI 参数与电机电气时间常数 `τ = Ls/Rs` 不匹配，积分项在低电感电机上引入过大相位滞后。

## 解决方案

按电机实际参数重新整定：

```
Kp = Ls * 带宽(rad/s)     # 带宽取开关频率 1/10 ~ 1/20
Ki = Rs / Ls
```

实测电机 `Rs=0.05 Ω, Ls=0.08 mH`，带宽取 5 kHz → `Kp=0.4, Ki=625`。

## 验证

重新整定后加载至 iq=8 A，电流环稳定，无振荡。
