## 现象

按达妙官方用户手册（V1.3）配置，上位机发送 CAN ID `0x001` 控制电机，驱动器无任何应答，示波器确认总线有波形。

## 排查过程

1. 用 CAN 分析仪抓包，发现驱动器实际应答在 `0x101`。
2. 逐字节对比手册协议帧，发现手册 ID 段未包含 `0x100` 偏移。
3. 查阅达妙官网最新固件更新日志（2025-08-12），确认 V2.0 固件将 ID 整体偏移 `0x100`，但手册未同步更新。

## 根因

用户手册版本落后于固件版本，CAN ID 段描述错误。

## 解决方案

- 临时：所有 CAN ID 手动加 `0x100`。
- 长期：向达妙技术支持索取 V2.0 固件配套手册，或降级固件至 V1.x。

## 验证

修改后发送 `0x101`，驱动器正常应答位置/速度/力矩数据。
