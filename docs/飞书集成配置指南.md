# 飞书集成配置指南

本文档指导飞书管理员将"电控调试简明指南"集成到重庆大学千里战队飞书组织，实现**在飞书中直接查看网页、跳转编辑/提交**。

## 1. 网页小组件（推荐，零开发）

飞书工作台支持添加"网页小组件"，把指南站点嵌入飞书侧边栏。

### 配置步骤（管理员操作）

1. 登录飞书管理后台（`admin.feishu.cn`）
2. 进入 **工作台** → **小组件管理** → **添加小组件**
3. 选择 **网页小组件**
4. 填写：
   - **名称**：电控调试指南
   - **链接**：`https://qianli2027.github.io/concise-guide-to-debugging/`
   - **图标**：可上传项目 logo 或用默认
5. 设置可见范围：选择"重庆大学千里战队"对应部门/群组
6. 保存并启用

### 效果

- 战队成员在飞书工作台侧边栏看到"电控调试指南"入口
- 点击直接在飞书内打开网页（无需跳转浏览器）
- 页面右上角"在 GitHub 编辑此页"仍可正常使用（跳转 GitHub 在线编辑器）

## 2. 群消息卡片（可选，快速入口）

在飞书群里发消息卡片，带"查看指南"和"提交文档"两个按钮。

### 方式 A：手动发送（零配置）

在飞书群里发一条消息，内容：

```text
📚 电控调试简明指南

收录电机、通信协议、控制算法、石山代码的疑难杂症。

🔗 查看指南：https://qianli2027.github.io/concise-guide-to-debugging/
📝 提交文档：https://github.com/QianLi2027/concise-guide-to-debugging/issues/new?template=submit-doc.yml
```

飞书会自动识别链接为卡片。

### 方式 B：机器人定时推送（需要 webhook）

如果战队有飞书群机器人，可以配置定时推送。

1. 在飞书群里添加 **自定义机器人**（群设置 → 群机器人 → 添加机器人）
2. 复制 webhook 地址（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxx`）
3. 用 curl 发送消息卡片：

```bash
curl -X POST 'https://open.feishu.cn/open-apis/bot/v2/hook/xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "msg_type": "interactive",
    "card": {
      "header": {
        "title": {"tag": "plain_text", "content": "📚 电控调试简明指南"},
        "template": "blue"
      },
      "elements": [
        {
          "tag": "div",
          "text": {"tag": "lark_md", "content": "收录电机、通信协议、控制算法、石山代码的疑难杂症"}
        },
        {
          "tag": "action",
          "actions": [
            {
              "tag": "button",
              "text": {"tag": "plain_text", "content": "查看指南"},
              "url": "https://qianli2027.github.io/concise-guide-to-debugging/",
              "type": "primary"
            },
            {
              "tag": "button",
              "text": {"tag": "plain_text", "content": "提交文档"},
              "url": "https://github.com/QianLi2027/concise-guide-to-debugging/issues/new?template=submit-doc.yml",
              "type": "default"
            }
          ]
        }
      ]
    }
  }'
```

## 3. 飞书文档嵌入（可选）

在飞书文档（知识库、群文档）里嵌入指南链接：

1. 打开飞书文档
2. 输入 `/网页` 或点击 **+** → **网页**
3. 粘贴 `https://qianli2027.github.io/concise-guide-to-debugging/`
4. 飞书会自动渲染为卡片预览

## 4. 权限与可见性

| 功能 | 权限要求 | 说明 |
|---|---|---|
| 网页小组件 | 飞书管理员 | 在工作台添加 |
| 群消息卡片 | 群成员 | 任何群成员可发链接 |
| 机器人推送 | 群主/管理员 | 需添加自定义机器人 |
| 编辑/提交 | GitHub 账号 | 点击"编辑此页"或"提交文档"跳转 GitHub |

## 5. 故障排查

- **网页小组件打不开**：检查 `qianli2027.github.io` 是否被公司/学校防火墙拦截，需 IT 加白名单。
- **"编辑此页"跳转 404**：确认 GitHub 仓库 `QianLi2027/concise-guide-to-debugging` 是公开仓库，且用户已登录 GitHub。
- **飞书内打开网页后样式错乱**：GitHub Pages 是静态站点，飞书内置浏览器兼容性良好；如有问题，引导用户点击右上角"在浏览器中打开"。

## 6. 维护

- 指南内容更新：直接改 GitHub 仓库，飞书小组件实时同步（无需重新配置）。
- 提交入口变更：如果 Issue 表单模板改了，更新本文档第 2 节的链接。
- 飞书组织变更：如果战队改名或重组，在飞书管理后台调整小组件可见范围。
